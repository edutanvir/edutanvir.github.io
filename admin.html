Connect to GitHub

Publishing saves availability.json in your GitHub repository. The key stays in this browser only.

"Edit without a token" loads the live file so you can download your changes and upload them to GitHub yourself.

How do I get a token? (one time, about 2 minutes)
  1. Open github.com/settings/personal-access-tokens/new while signed in.
  2. Name it Availability editor and choose an expiry date (90 days is a good start).
  3. Under Repository access, choose Only select repositories and pick edutanvir.github.io.
  4. Under Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above. You will not see it again, so keep it in a password manager.

The token can only touch this one repository, and you can delete it on GitHub at any time.
